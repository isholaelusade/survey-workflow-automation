## Overview

Survey Workflow Automation is a mobile-first operational platform built to improve the speed, consistency, and quality of property inspection workflows and reporting processes.

The platform focuses on streamlining operational tasks, reducing repetitive administration, and improving workflow efficiency through modern web technologies and AI-assisted tooling.

Built from real operational experience within UK housing inspections and stock condition surveying.

---

## Core Capabilities

* Mobile-first workflow management
* AI-assisted operational reporting
* Survey and inspection workflows
* Property reporting systems
* Workflow automation tooling
* Operational data handling
* Progressive Web App (PWA) support
* Offline-first workflow support

---

## Tech Stack

* React
* TypeScript
* Tailwind CSS
* Supabase
* Gemini AI
* Vite
* Progressive Web App (PWA)

---

## Why I Built This

After working within UK housing inspections and stock condition surveying, I saw how repetitive and manual many operational processes were.

This project started as an attempt to modernise operational workflows, improve reporting consistency, and reduce repetitive administrative work using AI-assisted tooling and mobile-first software systems.
